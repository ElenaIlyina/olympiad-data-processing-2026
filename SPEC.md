# Спецификация проекта: Обработка данных по олимпиадам 2026/27

## О проекте

Автоматизированный конвейер сбора, проверки и валидации расписания олимпиад
школьников (РСОШ) на сезон **2026/27** по трём направлениям:

| № таблицы | Направление                  | Кол-во олимпиад |
|-----------|------------------------------|-----------------|
| 1         | Информатика                  | 18              |
| 2         | Математика                   | 21              |
| 3         | Искусственный интеллект      | 3               |
| **Итого** |                              | **42**          |

Исходный результат — файл `olympiads_2026_27.html`.

---

## Часть 1 (задача Task 1): Обновление существующей таблицы

Опираясь на уже созданную локально таблицу, необходимо:

1. **Сохранить резервную копию** перед внесением любых изменений.
2. **Посетить каждый сайт** из таблицы и обновить информацию по трём полям:
   - даты **регистрации**;
   - даты **отборочного тура**;
   - даты **финального (заключительного) тура**.
3. **Подсветка дат жирным шрифтом** (`<b>...</b>`):
   - если дата **позже** `2026-09-01` → выделить **жирным**;
   - если дата **раньше** → оставить обычным шрифтом для справки.

### Правило подсветки

| Условие                                    | Формат                        |
|--------------------------------------------|-------------------------------|
| Дата ≥ `2026-09-01` (даты сезона 2026/27)  | `<b>...</b>` + класс `season-2026` |
| Дата < `2026-09-01` (справочная)           | обычный шрифт                 |

### Колонка «Площадки»

Колонку площадок разделить на две части: **отбор** и **финал**. Для каждого
тура указать одно из значений:

| Значение       | Условие                                                      |
|----------------|--------------------------------------------------------------|
| `онлайн`       | тур проводится онлайн                                        |
| `Спб`          | есть площадка в Санкт-Петербурге                             |
| `Мск`          | тур проходит **только** в Москве                             |
| `<город>`      | тур проходит в каком-то одном другом городе                   |
| `Регионы`      | ничего из вышеперечисленного не подходит                     |

Обязательно указывать `(прокторинг)` в скобках, если отбор проводится
с прокторингом.

**Итоговый формат колонки площадок:**
```
отбор: <значение>; финал: <финальное_значение>
```
Пример: `отбор: онлайн (прокторинг); финал: Спб`

### Ограничения

- Дополнить таблицу всей полученной информацией.
- **Новые строки не добавлять.**

## Требования к валидности выходного HTML

Выходной файл `olympiads_2026_27.html` должен удовлетворять:

- ровно **3 таблицы**;
- количество данных-строк: `[18, 21, 3]` (суммарно **42**);
- ровно **17** строк с классом `season-2026`;
- колонка площадок всегда в формате `отбор: ...; финал: ...`;
- у строк `season-2026` все даты жирные, у остальных — не жирные.

Проверяется скриптом `validate_table.py`.
